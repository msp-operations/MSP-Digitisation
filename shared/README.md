# Shared

What every tool should use from one place instead of keeping its own copy.

- **Design system (`msp-ui`)**: today each tool has its own copy, kept in step by hand ("kit sync"
  commits). Next step: one copy here, and each tool's publish step copies it in.
- **Login** (later): one sign-in for all tools through the MSP backend, with UM Microsoft accounts
  once ICTS approves; students and staff each see their own hub.
- **Feedback**: one address for every tool, msp-digital@maastrichtuniversity.nl.
