# Office tools

Offline tools the offices run on their own computer: they open an export, check it, and write an
Excel file. Nothing is uploaded.

- **BTR Grading Tool**: grades, booking check and cohort checklist for the BTR office.
- **ESD Record Check**: open bookings from before the BTR, for Education Support.

Not in this repository yet: their tests, code comments and guide screenshots still contain real
student data. They come in once those are replaced with made-up data.
